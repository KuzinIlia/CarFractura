# CarFractura

Гравець керує туреллю, встановленою на автомобілі. Під час руху попереду автомобіля з'являються вороги: спочатку вони знаходяться у стані очікування, а після наближення автомобіля починають переслідувати його та атакувати.
Метою гри стає проходження до кінця рівня, знищення ворогів та збереження HP автомобіля.

## Ігровий процес

- **Рух миші** — наведення турелі, яка автоматично стріляє під час руху.
Вороги генеруються у випадкових позиціях попереду автомобіля у стані `Idle`. Коли автомобіль потрапляє в радіус виявлення, ворог переходить до переслідування, наближається до автомобіля та атакує його. І автомобіль, і вороги мають власний запас здоров'я.

Проходження завершується у двох випадках:

- автомобіль долає необхідну дистанцію — **You Win**
- HP автомобіля знижується до нуля — **You Lose**

Після завершення проходження гру можна почати знову.

## Технічна інформація

- **Unity:** 6000.3.24f1
- **Мова:** C#
- **Dependency Injection:** Zenject
- **Цільова платформа:** WebGL
- Фізичний рух та взаємодія ворогів з автомобілем
- Спільний компонент `HealthUnit` для системи здоров'я
- Керування станами гри через `GameSession`
- Генерування ворогів через Zenject Factory
- Зациклення сегментів дороги замість створення всієї довжини рівня наперед
- Окремі компоненти для логіки автомобіля, турелі, ворогів та HUD
- Анімації ворогів для станів очікування, бігу, атаки та смерті
- Відображення HP автомобіля та ворогів
- Відображення прогресу проходження рівня та кількості знищених ворогів
